# TaskOne — Обработка банковских данных

## Описание:

Проект представляет собой набор утилит для работы с банковскими операциями. Реализованы функции маскировки номеров карт и счетов, форматирования дат, фильтрации транзакций по статусу и сортировки по времени. Подходит для учебных задач, тестовых заданий и интеграции в финансовые приложения.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/gallinakalutskaya-spec/TaskOne
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новый проект и начните добавлять задачи.
3. Назначайте сроки выполнения и приоритеты для задач, чтобы эффективно управлять проектами.
